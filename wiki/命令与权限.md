# 命令与权限

## 玩家命令

| 命令 | 说明 | 权限 |
|------|------|------|
| `/rpg` | 打开 RPG 道具编辑器 | `rpgforge.use` |

## 管理员命令

| 命令 | 说明 | 权限 |
|------|------|------|
| `/rpgforge` | 打开管理面板 | `rpgforge.admin` |
| `/rpgforge give <物品ID> [玩家名]` | 给予指定 RPG 物品 | `rpgforge.admin` |
| `/rpgforge list` | 列出所有 RPG 物品 | `rpgforge.admin` |
| `/rpgforge create <物品ID>` | 创建新的 RPG 物品 | `rpgforge.admin` |
| `/rpgforge delete <物品ID>` | 删除指定 RPG 物品 | `rpgforge.admin` |
| `/rpgforge reload` | 重载所有配置 | `rpgforge.admin` |
| `/rpgforge repair [数量]` | 修复手中物品耐久 | `rpgforge.admin.repair` |

## 配方命令

| 命令 | 说明 | 权限 |
|------|------|------|
| `/rpgforge recipe list` | 列出所有配方 | `rpgforge.admin` |
| `/rpgforge recipe create <配方ID> <物品ID> <类型>` | 创建新配方 | `rpgforge.admin` |
| `/rpgforge recipe delete <配方ID>` | 删除配方 | `rpgforge.admin` |
| `/rpgforge recipe give <配方ID>` | 给予配方产出物品（测试用） | `rpgforge.admin` |

配方类型：`shaped`（有序）、`shapeless`（无序）、`furnace`（熔炉）

## 权限节点

| 权限 | 说明 | 默认 |
|------|------|------|
| `rpgforge.use` | 打开 RPG 道具编辑器（/rpg） | OP |
| `rpgforge.admin` | RPGForge 管理权限（包含所有子权限） | OP |
| `rpgforge.admin.repair` | 修复 RPG 物品耐久 | OP（继承自 admin） |

## 命令示例

```
# 创建一个叫 flame_sword 的物品
/rpgforge create flame_sword

# 给自己一把烈焰剑
/rpgforge give flame_sword

# 给玩家 Steve 一把烈焰剑
/rpgforge give flame_sword Steve

# 修复手中物品全部耐久
/rpgforge repair

# 修复手中物品 50 点耐久
/rpgforge repair 50

# 创建一个有序配方，产出烈焰剑
/rpgforge recipe create flame_recipe flame_sword shaped

# 创建一个无序配方，产出生命药水
/rpgforge recipe create life_potion_recipe life_potion shapeless

# 列出所有配方
/rpgforge recipe list
```
