# 物品数据格式

RPGForge 的每个物品以 YAML 文件形式存储在 `plugins/RPGForge/items/` 目录下，文件名为 `<物品ID>.yml`。

本文档介绍数据格式，方便你手动编辑或批量导入道具。

---

## 基础结构

```yaml
id: flame_sword
material: DIAMOND_SWORD
name: '&c烈焰剑'
lore:
  - '&7一把燃烧着烈焰的神剑'
  - '&e右键发射火球'
custom-model-data: 0
unbreakable: false
max-durability: 0
durability-display: default
bar-color: '&a'
bar-length: 10
powers: []
```

---

## 字段说明

### 基础属性

| 字段 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `id` | 字符串 | 必填 | 物品唯一 ID，只能用英文、数字、下划线 |
| `material` | 字符串 | `STICK` | 物品材质（Material 枚举名） |
| `name` | 字符串 | 物品 ID | 显示名称，支持 `&` 颜色代码 |
| `lore` | 字符串列表 | 空 | 物品描述，每行一条，支持颜色代码 |
| `custom-model-data` | 整数 | `0` | 自定义模型数据（用于资源包） |
| `unbreakable` | 布尔 | `false` | 是否不可破坏 |

---

### 耐久相关

| 字段 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `max-durability` | 整数 | `0` | 自定义最大耐久，0=使用材质默认 |
| `durability-display` | 字符串 | `default` | 耐久显示模式：`default`、`bar`、`numeric`、`hidden` |
| `bar-color` | 字符串 | `&a` | 进度条颜色（仅 bar 模式有效） |
| `bar-length` | 整数 | `10` | 进度条长度（仅 bar 模式有效） |

---

### Powers

`powers` 是一个列表，每个元素代表一个 Power。

**通用字段**：

| 字段 | 类型 | 说明 |
|------|------|------|
| `type` | 字符串 | Power 类型 ID（如 `lightning`、`explosion`） |
| `triggers` | 字符串列表 | 绑定的 Trigger 列表 |
| `params` | Map | Power 的参数（具体参数取决于 Power 类型） |
| `conditions` | 列表 | 条件列表，所有条件满足才执行 |
| `fail-message` | 字符串 | 触发失败时的提示消息（可选） |

---

## 完整示例

```yaml
id: flame_sword
material: DIAMOND_SWORD
name: '&c烈焰剑'
lore:
  - '&7一把燃烧着烈焰的神剑'
  - '&e右键发射火球'
  - '&e攻击点燃目标'
custom-model-data: 0
unbreakable: false
max-durability: 2000
durability-display: numeric

powers:
  # Power 1: 右键发射火球
  - type: fireball
    triggers:
      - RIGHT_CLICK
    params:
      yield: 2.0
      cooldown: 3
    conditions:
      - type: chance
        params:
          value: 80.0
        fail-message: '&c火球发射失败！'
    fail-message: '&c技能无法使用'

  # Power 2: 攻击命中点燃
  - type: flame
    triggers:
      - HIT
    params:
      seconds: 5

  # Power 3: 攻击消耗耐久
  - type: durability
    triggers:
      - HIT
    params:
      amount: 1
```

---

## Condition 格式

每个 Condition 的结构：

| 字段 | 类型 | 说明 |
|------|------|------|
| `type` | 字符串 | 条件类型（如 `chance`、`health_below`、`permission`） |
| `params` | Map | 条件参数 |
| `fail-message` | 字符串 | 该条件不满足时的提示（可选） |

**示例**：

```yaml
conditions:
  - type: health_below
    params:
      value: 4.0
    fail-message: '&c血量足够，无法激发潜能！'
  - type: permission
    params:
      value: vip.gold
    fail-message: '&c你需要 VIP 才能使用此技能'
```

## 小贴士

1. **修改后重载**：手动修改 YAML 文件后，使用 `/rpgforge reload` 重新加载
2. **颜色代码**：使用 `&` 代替 `§`，插件会自动转换
3. **备份**：定期备份 `items/` 目录和 `recipes.yml` 文件
4. **ID 命名**：建议使用小写字母 + 下划线，如 `fire_sword`、`life_potion`
5. **物品 Lore**：Lore 中的耐久行会在构建物品时自动追加，不需要手动写
