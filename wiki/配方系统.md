# 配方系统

RPGForge 内置配方系统，支持有序合成、无序合成和熔炉熔炼三种配方类型。玩家可以通过合成获得 RPG 物品。

---

## 配方类型

### SHAPED — 有序配方

物品必须按照特定的形状摆放才能合成。适合有明确合成图案的物品（如剑、工具）。

**特点**：
- 需要指定形状（3x3 矩阵）
- 每个字符对应一种材料
- 位置严格对应

---

### SHAPELESS — 无序配方

只要材料种类和数量正确，放在工作台的任何位置都可以合成。适合材料简单的物品（如药水、食物）。

**特点**：
- 只需要指定材料列表
- 材料可以任意摆放
- 最多 9 种材料

---

### FURNACE — 熔炉配方

放在熔炉里熔炼获得。适合矿石冶炼、食物烹饪等。

**特点**：
- 指定输入材料和输出物品
- 可以设置经验和熔炼时间
- 需要燃料

---

## 命令管理

### 列出所有配方

```
/rpgforge recipe list
```

显示所有已注册的配方，包括类型、产出物品、产出数量。

---

### 创建配方

```
/rpgforge recipe create <配方ID> <产出物品ID> <类型>
```

**类型**：`shaped`（有序）、`shapeless`（无序）、`furnace`（熔炉）

**示例**：
```
# 创建一个有序配方，产出烈焰剑
/rpgforge recipe create flame_sword_recipe flame_sword shaped

# 创建一个无序配方，产出生命药水
/rpgforge recipe create life_potion_recipe life_potion shapeless

# 创建一个熔炉配方，产出雷霆战锤
/rpgforge recipe create thunder_hammer_recipe thunder_hammer furnace
```

> 创建后配方是空的，需要在配置文件中编辑具体的材料。

---

### 删除配方

```
/rpgforge recipe delete <配方ID>
```

删除指定配方，同时从 Bukkit 中注销。

---

### 给予配方产出物品（测试用）

```
/rpgforge recipe give <配方ID>
```

直接给你自己一个配方的产出物品，用于测试。

---

## 配置文件

配方存储在 `plugins/RPGForge/recipes.yml` 文件中。

### 有序配方示例

```yaml
recipes:
  flame_sword_recipe:
    id: flame_sword_recipe
    result-item-id: flame_sword
    result-amount: 1
    type: shaped
    shape:
      - " F "
      - " I "
      - " S "
    ingredients:
      F: BLAZE_POWDER
      I: IRON_INGOT
      S: STICK
```

**shape** 是一个字符串数组，每个字符串代表一行：
- 每个字符代表一个格子
- 空格代表空
- 字符在 `ingredients` 中映射到具体的材料

**ingredients** 是字符到 Material 的映射。

---

### 无序配方示例

```yaml
  life_potion_recipe:
    id: life_potion_recipe
    result-item-id: life_potion
    result-amount: 1
    type: shapeless
    ingredients:
      - GLISTERING_MELON_SLICE
      - GLASS_BOTTLE
      - GOLD_INGOT
```

**ingredients** 是 Material 列表，顺序无关。

---

### 熔炉配方示例

```yaml
  thunder_hammer_recipe:
    id: thunder_hammer_recipe
    result-item-id: thunder_hammer
    result-amount: 1
    type: furnace
    input: DIAMOND
    experience: 5.0
    cooking-time: 200
```

- **input**：输入的材料
- **experience**：熔炼完成后获得的经验
- **cooking-time**：熔炼时间（tick，20 tick = 1 秒）

---

## 完整示例

下面是一个完整的 `recipes.yml` 示例：

```yaml
recipes:
  # 烈焰剑 —— 有序配方
  flame_sword_recipe:
    id: flame_sword_recipe
    result-item-id: flame_sword
    result-amount: 1
    type: shaped
    shape:
      - " F "
      - " I "
      - " S "
    ingredients:
      F: BLAZE_POWDER
      I: IRON_INGOT
      S: STICK

  # 生命之杖 —— 无序配方
  life_staff_recipe:
    id: life_staff_recipe
    result-item-id: life_staff
    result-amount: 1
    type: shapeless
    ingredients:
      - GOLDEN_APPLE
      - STICK
      - DIAMOND

  # 雷霆战锤 —— 熔炉配方
  thunder_hammer_recipe:
    id: thunder_hammer_recipe
    result-item-id: thunder_hammer
    result-amount: 1
    type: furnace
    input: NETHERITE_INGOT
    experience: 10.0
    cooking-time: 400
```

---

## 注意事项

1. **材料只能是普通 Material**：目前配方的原料只支持原版物品（Material），不支持其他 RPG 物品作为原料
2. **产出必须是 RPGItem**：配方的产出物必须是已存在的 RPG 物品
3. **重载配方**：修改 `recipes.yml` 后使用 `/rpgforge reload` 重新加载
4. **配方冲突**：如果配方 ID 或形状与原版/其他插件冲突，可能无法正常工作
5. **首次运行**：插件首次启动时会自动创建 3 个示例配方，可以参考或删除
