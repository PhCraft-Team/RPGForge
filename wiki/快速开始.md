# 快速开始

5 分钟上手 RPGForge，制作你的第一个 RPG 道具！

## 安装插件

1. 下载 `RPGForge-1.0.0.jar`
2. 放入服务器的 `plugins/` 文件夹
3. 启动服务器
4. 输入 `/rpgforge`，如果能看到插件信息说明安装成功

> 依赖：Paper 1.21+  
> 可选依赖：Vault（用于金币消耗功能）

## 制作第一个道具

我们来做一把「烈焰剑」——右键发射火球，攻击命中时点燃目标。

### 第一步：创建物品

1. 输入 `/rpgforge create flame_sword` 创建一个 ID 为 `flame_sword` 的物品
2. 输入 `/rpgforge` 打开物品列表，点击「烈焰剑」进入编辑界面

### 第二步：设置基础属性

在编辑界面中：
- 点击「物品材质」，选择 **钻石剑 (DIAMOND_SWORD)**
- 点击「显示名称」，输入 `&c烈焰剑`（&c 是红色）
- 点击「物品描述」，添加描述：`&7一把燃烧着烈焰的神剑`

### 第三步：添加 Power — 发射火球

1. 点击「添加 Power」
2. 在列表中找到「发射火球」，点击选择
3. 进入 Power 编辑界面：
   - **爆炸威力**：设为 `2.0`
   - **冷却时间**：设为 `3` 秒
   - **触发方式**：勾选「右键」（默认已勾选）
4. 点击「返回」保存

### 第四步：添加 Power — 燃烧

1. 再次点击「添加 Power」
2. 找到「燃烧」，点击选择
3. 进入编辑：
   - **燃烧秒数**：设为 `5`
   - **触发方式**：勾选「攻击命中 (HIT)」
4. 点击「返回」保存

### 第五步：获取物品并测试

1. 输入 `/rpgforge give flame_sword` 获取物品
2. **右键** — 发射火球！
3. **左键攻击生物** — 目标会燃烧起来！

## 进阶：添加触发条件

让我们给烈焰剑加一个「30% 概率触发」的条件：

1. 打开火球 Power 的编辑界面
2. 找到「条件列表」，点击「添加条件」
3. 选择「概率 (CHANCE)」
4. 设置数值为 `30`（30% 概率）
5. 失败消息设为 `&c技能触发失败！`
6. 保存

现在右键使用火球时，只有 30% 的概率会成功发射，失败时会提示消息。
